# SMI-6441: doc-vocab-keeplist.txt — hand-curated documentation-vocabulary
# subtraction list for scripts/gen-weak-password-lexicon.mjs.
#
# THIS FILE IS THE SOLE GUARD against reopening the `sensitive_path`
# documentation false-positive class that SMI-5207 closed. The generator
# subtracts every token below from the filtered SecLists top-10000 list
# before emitting COMMON_WEAK_PASSWORDS. Two failure directions, both
# silent if this file drifts:
#   - A careless ADDITION here silently WEAKENS detection (removes a real
#     common password from the veto set).
#   - A careless OMISSION here silently CREATES a false positive (an
#     ordinary documentation word gets vetoed to HIGH severity).
#
# Every entry below must be justifiable as ordinary documentation/config/
# infrastructure vocabulary — not as "a word that happens not to be a
# common password". Any addition or removal requires re-running Wave 2's
# fixture matrix (docs/internal/implementation/smi-6441-weak-password-veto.md,
# Wave 2 Step 3) before it is safe to regenerate and commit.
#
# Format: whitespace-separated lowercase tokens, any number per line.
# Lines starting with `#` are comments. Blank lines are ignored.
#
# See also: the generator's PROSE_STOPWORDS disjointness gate (a SEPARATE,
# non-interchangeable mechanism — a hard-fail invariant check, not a
# subtraction; see docs/internal/implementation/smi-6441-weak-password-veto.md
# § item 2) and data/wordlists/README.md.
