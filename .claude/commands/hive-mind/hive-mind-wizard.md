# hive-mind-wizard (deprecated)

**Deprecated / historical.** There is no wizard or guided-setup command in v3 — this file is kept for historical reference only and does not describe a live command. The global `-i/--interactive` flag is not a wizard equivalent.

For hive-mind setup in v3, use `hive-mind init` (see [hive-mind-init.md](./hive-mind-init.md)) with explicit flags, or `hive-mind spawn --claude -o "<objective>"` to hand setup off to Claude Code interactively.
